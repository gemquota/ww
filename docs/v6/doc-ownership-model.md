# Documentation Ownership Model — V6-D2#2

## Owners by Area

| Document Area | Primary Owner | Reviewer |
|---|---|---|
| User guides (getting-started, troubleshooting) | Product Manager | Tech Writer |
| API reference | DevEx Lead | Maintainer |
| Architecture docs | Lead Architect | All maintainers |
| Tutorials | Developer Advocate | Community |
| Contributing guide | Community Manager | Maintainers |
| Deployment docs | DevOps Lead | Release Manager |

## Responsibilities
- **Primary Owner**: Keeps doc accurate, responds to PRs, plans updates
- **Reviewer**: Reviews accuracy, consistency, and completeness

## Onboarding New Docs
1. Owner identified in PR
2. Doc reviewed for:
   - Technical accuracy
   - Style guide compliance
   - Cross-linking to related docs
3. Added to cross-reference map

## Dispute Resolution
If two owners disagree on doc content:
1. Discuss on the PR (max 5 days)
2. Escalate to maintainers if unresolved
3. Maintainer decision is final
