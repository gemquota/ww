# Documentation Usability Testing — V6-D4#1

## Testing Methods

### 1. First-Click Testing
- Give user a task (e.g., "Install and run the bridge")
- Observe where they click first
- Measure time to first correct action

### 2. Task Completion
- Define 5 key tasks
- Measure completion rate and time
- Target: >80% completion in <5 minutes

### 3. Findability
- Ask users to find specific information
- Measure search vs navigation paths
- Target: <3 clicks to any doc

## Key Tasks to Test
1. Install the bridge and run a query
2. Find troubleshooting for API errors
3. Understand the agent hierarchy
4. Set up a development environment
5. Find and run the test suite

## Iteration Loop
1. Test (5 users)
2. Identify top 3 issues
3. Fix issues
4. Re-test
