# Structured Learning Path — V6-O3#1

## Level 1: Beginner (Week 1)
- [ ] Install and run the bridge
- [ ] Run your first query
- [ ] Understand the 3-tier agent hierarchy
- [ ] Use basic tools: read_file, write_file

## Level 2: Intermediate (Week 2-3)
- [ ] Create custom prompt templates
- [ ] Use the plugin system
- [ ] Configure permissions and sandbox
- [ ] Run the test suite
- [ ] Use checkpoints and undo

## Level 3: Advanced (Week 4+)
- [ ] Add new tool implementations
- [ ] Create custom agents
- [ ] Extend the evaluation framework
- [ ] Contribute to the codebase
- [ ] Write ADRs

## Skill Assessment Points
- End of Level 1: Can run bridge independently
- End of Level 2: Can extend bridge capabilities
- End of Level 3: Can contribute effectively
