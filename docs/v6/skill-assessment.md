# Skill Assessment at Milestones — V6-O3#2

## Assessment Points

### After 1 week (Beginner Check)
- Can run `python gemini_bridge.py --help`?
- Can run a simple query in script mode?
- Can read a file using tool:read_file?
- Can identify the three agent tiers?

### After 3 weeks (Intermediate Check)
- Can create a custom prompt template?
- Has contributed a documentation fix?
- Can run the full test suite?
- Understands checkpoint/undo flow?

### After 6 weeks (Advanced Check)
- Has implemented a tool or plugin?
- Has contributed a code change?
- Can explain the memory architecture?
- Has reviewed another contributor's PR?

## Assessment Methods
- Self-assessment checklist
- PR review feedback
- Test suite passes
- Mentor evaluation
