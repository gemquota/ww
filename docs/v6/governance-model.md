# Community Governance Model — V6-C1#3

## Structure

### Maintainers (3-5 people)
- Merge authority
- Release management
- Architectural decisions
- Elected by existing maintainers (consensus)

### Committers (5-15 people)
- Review authority
- Issue triage
- Feature branch creation
- Nominated by maintainers

### Contributors (everyone else)
- PR submission
- Bug reports
- Documentation improvements
- No special authority needed

---

## Decision Making
- **Technical decisions**: Lazy consensus (72h quiet period)
- **Architecture decisions**: ADR process with maintainer vote
- **Governance changes**: Full maintainer consensus

## Conflict Resolution
1. Discussion on issue/PR (7 days)
2. Maintainer mediation
3. Escalation to project owner
