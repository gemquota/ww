# V6 documentation archive

This directory contains historical V6 quality, process, operations and documentation proposals. It is retained for context and is not a specification of the current WW runtime.

The supported runtime is described in [the architecture review](../architecture-review.md). Current architecture decisions are listed in [the ADR index](../adr/INDEX.md). Do not implement a V6 proposal without first checking whether the relevant behavior still exists and whether it belongs in the shared ConversationRuntime.
