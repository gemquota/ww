# Feedback Collection — V6-O4#4

## Channels

### 1. In-App Feedback
- `/feedback` command in TUI
- Opens form: rating (1-5) + free text
- Stored in telemetry database

### 2. GitHub Issues
- Bug report template
- Feature request template
- Performance issue template

### 3. Periodic Surveys
- Quarterly contributor survey
- Annual user survey
- Post-onboarding survey (after first week)

## Analysis Loop
1. Collect feedback
2. Categorize (bug/feature/usability/docs)
3. Prioritize (impact × frequency)
4. Act (create issues, plan work)
5. Close the loop (announce changes)

## Metrics to Track
- Net Promoter Score (NPS)
- Feature satisfaction (per feature)
- Documentation helpfulness rating
- Response time to issues
