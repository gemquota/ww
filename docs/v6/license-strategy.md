# License Strategy — V6-C3#1

## Current License
MIT License — permissive, allows commercial use, modification, and redistribution.

## Strategy

### Why MIT
- Maximizes adoption and contribution
- Compatible with corporate policies
- No friction for dependency inclusion
- Industry standard for AI/ML tools

### Governance
- License will not change for existing code
- New contributors agree to MIT licensing
- Third-party dependencies must be MIT-compatible

## License Compatibility
| Dependency Type | Allowed Licenses | Prohibited Licenses |
|---|---|---|
| Core deps | MIT, Apache 2.0, BSD | GPL, AGPL, Proprietary |
| Optional deps | MIT, Apache 2.0, BSD, LGPL | AGPL, Proprietary |
| Dev deps | Any OSI-approved | Proprietary |
