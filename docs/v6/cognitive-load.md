# Cognitive Load in Documentation — V6-D4#3

## Principles

### Minimize Extraneous Load
- One concept per page/section
- No unrelated information in examples
- Consistent terminology throughout
- Progressive disclosure: start simple, add detail later

### Optimize Germane Load
- Worked examples before abstract concepts
- Analogies to familiar systems
- Visual diagrams for relationships
- Code snippets with annotations

### Manage Intrinsic Load
- Prerequisites clearly stated
- Chunk complex topics into <7 items
- Each section builds on previous
- Summary at end of each major section

## Checklist
- [ ] Can a junior developer follow this?
- [ ] Are there concrete examples?
- [ ] Are unfamiliar terms defined?
- [ ] Is there a clear next step after reading?
