# Documentation Accessibility — V6-D4#4

## Standards
- WCAG 2.1 Level AA compliance
- Readable without color alone
- Alt text for all images
- Semantic heading structure

## Markdown Requirements
- Headings in order (h1 → h2 → h3, never skip levels)
- Lists use `-` consistently
- Code blocks specify language
- Tables have header rows
- Links have descriptive text (not "click here")

## Diagram Accessibility
- Every diagram has a text description
- Color is never the only differentiator
- Diagrams available as SVG (not just images)

## Screen Reader Notes
- Mermaid diagrams render as text
- No ASCII art that screen readers can't parse
- Image alt text describes the full content
