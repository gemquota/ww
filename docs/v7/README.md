# V7 documentation archive

This directory contains historical V7 refactoring and operational proposals. It is retained for context and is not a specification of the current WW runtime.

The old agent hierarchy and DAG executor are not the supported application path. The current terminal and browser clients use the shared ConversationRuntime. See [the architecture review](../architecture-review.md) and [current ADRs](../adr/INDEX.md) before reusing any V7 proposal.
